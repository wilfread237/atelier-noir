# Security Policy

## Supported versions

Only the latest release of Atelier Noir and Atelier Noir Core receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Use GitHub's private reporting instead: **Security → Report a vulnerability** on the [repository page](https://github.com/wilfread237/atelier-noir/security/advisories/new).

Include the affected version, the steps to reproduce and the potential impact. You should receive an answer within a week. Once a fix is released, you will be credited in the changelog unless you prefer to stay anonymous.
