## [1.1.0] — First public release

### Added
- Atelier Noir child theme (parent: Hello Elementor): editorial home with full-screen video hero, founder biography, full-screen Services page, projects, contact and booking forms, legal page templates, optional WooCommerce shop.
- Guided setup page (**Appearance → Atelier Noir Setup**) with one-click demo content.
- Companion plugin **Atelier Noir Core**: projects post type, Open Graph tags, MailPoet newsletter form and popup with explicit consent, demo import, WooCommerce single-currency setup, branded emails and delivery status. Bundled in the theme zip and installable from the setup page.
- Self-hosted open-source fonts: Outfit (headings) and Inter (body), SIL Open Font License.
- Release workflow producing `atelier-noir.zip` and `atelier-noir-core.zip`.
