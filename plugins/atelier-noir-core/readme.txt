Companion plugin for the Atelier Noir theme: projects, SEO, newsletter, demo import and WooCommerce extras.

== Description ==

Atelier Noir Core keeps the features that should not disappear when you change theme:

* **Projects** custom post type (`an_project`) with full-screen image and video sections, paginated archive.
* **Open Graph**: branded share title and image on every page (works alongside Yoast SEO).
* **Newsletter** footer form and popup, powered by MailPoet (hidden when MailPoet is not active).
* **Demo import**: one-click Elementor pages, posts, products, menu and Customizer settings.
* **WooCommerce**: single-currency (USD) setup, branded emails and an in-house delivery status for orders.

The plugin requires the Atelier Noir theme and shows a notice if the theme is not active.

Source code, issues and releases: https://github.com/wilfread237/atelier-noir

== Installation ==

1. Activate the Atelier Noir theme.
2. Go to **Appearance → Atelier Noir Setup** and click **Install** next to Atelier Noir Core (the plugin ships inside the theme zip).
3. Or upload `atelier-noir-core.zip` from the latest GitHub release via **Plugins → Add New → Upload Plugin**.
