1. Structure du thème enfant

Le dossier atelier-noir contient toutes les personnalisations du thème Atelier Noir (parent : Hello Elementor). Ne pas modifier le thème parent.

  • functions.php — chargement des modules, WooCommerce, Elementor.
  • header.php / footer.php — en-tête et pied Studio.
  • front-page.php — accueil (Personnaliseur ou page / Elementor).
  • template-*.php — modèles de page (Contact, Services, légal…).
  • assets/css/ et assets/js/ — styles et scripts.
  • woocommerce/ — boutique, compte, e-mails.
  • inc/ — Personnaliseur, import contenu, devise, newsletter.

2. Couleurs, polices, loader

Apparence → Personnaliser

  • Rubrique Atelier Noir — couleurs : texte principal, fond, accent.
  • Typographie : polices titres et corps (Google Fonts).
  • Loader (accueil) : activation, textes, couleurs.

3. Page Services (4 panneaux plein écran)

Modèle de page : Atelier Noir — Services.

Apparence → Personnaliser → Atelier Noir — page Services (modèle PHP) : pour chaque bloc, image (médiathèque), textes, vidéo, slug pour le lien vers Contact.

4. Accueil (secours Personnaliseur)

Si l’accueil s’appuie sur le Personnaliseur : vidéo hero, poster, textes, bloc « Le studio » (image, titre, paragraphe, bouton).

5. Produits WooCommerce

Produits dans l’admin : images, prix, descriptions — comme d’habitude. Le design des cartes est dans le thème enfant (woocommerce.css).

6. Pages Elementor

Les pages en modèle par défaut avec mise en page enregistrée dans Elementor se modifient dans Pages → Modifier avec Elementor. La boutique catalogue reste gérée par WooCommerce (Elementor Pro pour un gabarit d’archive complet).

7. Import contenu

Apparence → Studio · Import contenu : applique un jeu de réglages et de pages d’exemple. À affiner avec le client (images, prix, mentions légales).

8. Fichier Markdown

Le fichier docs/DOCUMENTATION.md dans le thème reprend ces thèmes avec plus de détail pour les développeurs.
